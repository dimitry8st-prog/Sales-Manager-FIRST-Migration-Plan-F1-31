# Sales Manager FIRST — Migration Plan F1-31

Решение задания F1-31, ревизия R1. Подготовлено к внешней приёмке.

## Назначение

`build_migration_plan(root, *, schema="runtime_next")` проверяет три исходных SQL-файла по фиксированным путям и SHA-256, затем возвращает неизменяемый план. SQL не выполняется.

Статус результата: `PLANNED_NOT_AUTHORIZED`. Интеграция: `NOT_CONNECTED`. Проверки базы и e2e: `NOT_RUN`.

## Состав

- `04_Dmitriy_Intern_F1-31/` — полный пакет: исходные требования, реализация, публичные и собственные тесты, документация и return/.
- `deliverables/F1-31_RETURN_R1.zip` — проверенный архив для сдачи.

## Логика

1. Проверить schema: разрешена только обычная строка runtime_next.
2. Проверить тип root, запретить .., symlink и Windows junction.
3. Проверить безопасность всех путей и наличие обычных файлов.
4. Прочитать исходные байты и проверить фиксированные SHA-256.
5. Декодировать UTF-8 без замены переводов строк и placeholders.
6. Вернуть три записи в порядке sales → inbox → leases и точную декларацию required_preflight.

required_preflight перечисляет внешние проверки инженера внедрения. Он не подтверждает существование или совместимость foundation и не разрешает выполнение SQL.
